# PokerJudge

Texas Hold'em hand evaluator and winner judge. Single file, no dependencies, no build step.

- Run: open `index.html` in a browser.
- Test the engine: `node test.js` (extracts the engine from `index.html`).
- 2–6 players, 5 community cards, best 5 of 7, full kicker and split-pot handling.
